# 요알못 나혼산 · 저녁 메뉴 정하기

혼자 살면서 요리를 잘 못하는 사람이, 최근에 먹은 메뉴를 빼고 오늘 저녁 메뉴를 추천받는 웹페이지입니다.

## 왜 만들었나

저녁 메뉴를 정할 때 최근에 먹지 않은 메뉴가 바로 떠오르지 않습니다. 지금은 머릿속 기억으로 고르고, 안 떠오르면 간단히 때웁니다. 이 페이지는 그 과정을 줄이려는 것입니다.

## 사용 순서

1. 최근 며칠간 먹은 저녁 메뉴를 고릅니다. 목록에 없으면 "기타" 칸에 직접 씁니다.
2. 오늘 땡기는 분야를 누릅니다. 건강식, 한식, 일식, 중식, 양식, 분식 중에서 고릅니다.
3. 먹은 메뉴를 뺀 저녁 메뉴를 추천받습니다.

추천받아 고른 메뉴의 횟수는 저장해 두었다가 내 취향 베스트 1~5위로 보여 줄 계획입니다.

## 현재 상태

지금은 첫 화면만 있습니다. 버튼은 모양만 있고 눌러도 동작하지 않습니다.

| 항목 | 상태 |
| --- | --- |
| 첫 화면 레이아웃 (모바일 포함) | 완료 |
| 먹은 메뉴 선택, 기타 직접 입력칸 | 화면만 있음, 동작 연결 전 |
| 분야 선택 버튼 6개 | 화면만 있음, 동작 연결 전 |
| 분야별 추천 메뉴 목록 | 예시 값, 나중에 연결 |
| 취향 베스트 1~5위 저장 | 예시 값, 나중에 연결 |

화면에 보이는 "메뉴 A~D" 등은 예시 값이며 실제 메뉴가 아닙니다.

## 파일

브라우저에서 파일을 열면 바로 확인할 수 있습니다.

- 고른 메뉴 횟수 저장과 베스트 1~5위 표시
